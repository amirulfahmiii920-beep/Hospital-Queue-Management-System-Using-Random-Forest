# Hospital Queue Management System Using Random Forest for Predictive Analysis

An AI-integrated hospital queue management system developed exclusively for the Android platform. This application aims to optimize patient wait times and streamline hospital operations utilizing predictive analysis.

## Core Features
* **Predictive Queue Management:** Utilizes Random Forest algorithms to estimate waiting times.
* **AI Chatbot Assistance:** Integrated with Google Gemini AI to assist patients with inquiries.
* **Smart Push Notifications:** Automated and scheduled alerts powered by OneSignal to keep patients updated.
* **Secure Cloud Backend:** Real-time database management and user authentication utilizing Supabase.

## Getting Started

To test or run this project on your local machine, follow the setup instructions below.

### Prerequisites
* Flutter SDK
* VS Code or Android Studio
* Android Emulator or a physical Android device

### Installation & Setup
1. Clone this repository to your local machine.
2. Open the project in your IDE and run `flutter pub get` in the terminal to install all required dependencies.
3. Locate the `.env.example` file in the root directorygit add README.md.
4. Duplicate the file and rename the copy to `.env`.
5. Open the `.env` file and insert the necessary API keys for Supabase, OneSignal, and Google Gemini.
6. Build and run the application exclusively on an Android emulator or device.
